# Tri-Pillars Day 8 🚀

## 📌 About

This repository contains my **Day 8 practice programs** from the Tri-Pillars learning journey, focused on **Java Collections and Wrapper Classes**.

The programs are simple hands-on examples that helped me understand how different Java collection types work, how elements are stored and accessed, and how different collection implementations behave.

## 🛠️ Topics Covered

* `ArrayList`
* Adding, accessing, updating and removing elements
* Searching elements using `contains()` and `indexOf()`
* Finding collection size
* Sorting collections
* Ascending and descending order
* Mixed-type `ArrayList`
* `HashSet`
* `LinkedHashSet`
* `TreeSet`
* Stack operations
* Wrapper Classes

## 📂 Files

| File                  | Description                                                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ArrayList1.java`     | Demonstrates common `ArrayList` operations such as `add()`, `get()`, `set()`, `remove()`, `size()`, `contains()`, `indexOf()`, `sort()` and `clear()`. |
| `ArrayListMixed.java` | Demonstrates storing different types of objects in an `ArrayList<Object>`.                                                                             |
| `SetComparison.java`  | Compares `HashSet`, `LinkedHashSet`, and `TreeSet` based on ordering and sorting behavior.                                                             |
| `Stack.java`          | Practice implementation related to Java Stack concepts.                                                                                                |
| `StackDemo.java`      | Demonstrates stack operations using Java.                                                                                                              |
| `WrapperClass.java`   | Demonstrates Java Wrapper Classes and their usage.                                                                                                     |

## 💻 Technologies Used

* **Java**
* Java Collections Framework
* Object-Oriented Programming concepts

## 🎯 Learning Objective

The main goal of this practice was to build a stronger understanding of **Java's Collections Framework** and learn when different collection types can be used.

Through these programs, I practiced:

* Managing groups of objects
* Working with dynamic lists
* Understanding ordered and unordered collections
* Performing common collection operations
* Understanding different Set implementations
* Working with Stack data structures
* Understanding Wrapper Classes

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/syedaakifzain/Tri-pillars-Day8.git
```

2. Open the project in any Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

3. Compile and run the required `.java` file.

Example:

```bash
javac ArrayList1.java
java ArrayList1
```
